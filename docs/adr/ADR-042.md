# ADR-042 — Seed de demostración local (profile `demo`)

**Estado:** Accepted · **Fecha:** 2026-09-23 · **Change:** `demo-seed`

**Origen:** cierre F3 de construcción (sin discovery) + reflect critic/business.
Relacionados: ADR-012 (Argon2id), ADR-009/036 (search outbox/backfill).

## Contexto

Tras filas 1–26 (+ reopen en vuelo), el producto cubre el demo en browser, pero el
setup manual es largo. Hace falta un seed reproducible acotado al stack local.

## Decisión

1. **CLI canónico:** `pnpm nx run api:seed-demo`. Única vía de escritura de datos demo.
2. **Compose:** Meilisearch `profiles: ['search', 'demo']`. Profile `demo` no arranca
   api/worker/web ni siembra por mongosh/otra vía.
3. **Credenciales fijas (solo local):**
   - `ana@demo.linkvault.local` / `Demo-pass-Ana-12345!`
   - `bob@demo.linkvault.local` / `Demo-pass-Bob-12345!`
   Passwords con el mismo Argon2id que auth.
4. **Guards (fail closed):** `ALLOW_DEMO_SEED=true`; no `NODE_ENV=production`;
   **cada** host de `MONGODB_URI` ∈
   `{localhost, 127.0.0.1, ::1, mongo, host.docker.internal}`.
5. **Search:** el seed NO llama al SDK Meili; reutiliza `BackfillSearch` / outbox.
6. **F3:** construcción cerrada; `discovery` diferido a iteración post-v1.
7. **Plan:** fila **28** en `docs/design-v0.2.md` §6 (tras `job-link-reopen` fila 27).

## Alternativas descartadas

- Sembrar desde un contenedor con lógica distinta al CLI.
- Upsert síncrono a Meili desde el seed.
- Discovery en este change.

## Consecuencias

- RUNBOOK / `docs/demo.md` con checklist y skips (CV/MinIO, reopen UI si #47 abierto).
- `ALLOW_DEMO_SEED` nunca en compose prod.
