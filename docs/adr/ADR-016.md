# ADR-016 — Sin embeddings ni streaming estructurado en MVP

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
Ninguna tarea del MVP los usa (Critic C17/C18).

## Decisión
EmbeddingProvider y streaming se posponen a F2/F3. Progreso de análisis por SSE de etapas.

## Consecuencias
Menos superficie en libs/ai para el primer release.
