# ADR-012 — Auth con refresh cookie rotativa

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
JWT en localStorage expuesto a XSS (Critic C11).

## Decisión
Access token en memoria; refresh token en cookie httpOnly SameSite=Lax con rotación y detección de reuso; Argon2id.

## Consecuencias
Endpoint /auth/refresh; revocación por familia de tokens.
