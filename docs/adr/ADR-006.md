# ADR-006 — MongoDB + Redis + MinIO

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
Documentos ricos (previews, análisis) y colas.

## Decisión
MongoDB principal, Redis para BullMQ/caché, MinIO para CVs. Meilisearch en F2.
· **Enmendado por ADR-052 §Enmiendas, punto 3 (2026-09-27).** MinIO deja de ser el almacén de los CV: lo sustituye SeaweedFS 4.47, elegido con una matriz ejecutada (ADR-052 «Elección»).

## Consecuencias
Mongo como replica set (ADR-009).
