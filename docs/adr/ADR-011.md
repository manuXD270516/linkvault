# ADR-011 — Nx como orquestador del monorepo

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
pnpm workspaces sin grafo de tareas ni caché (Critic C10).

## Decisión
Nx con generadores oficiales para Nest y Angular; `nx affected` en hooks y CI.

## Consecuencias
Salida documentada a Turborepo si Nx pesa.
