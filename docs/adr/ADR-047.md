# ADR-047 — Extensión Firefox + CORS multi-browser (enmienda ADR-038)

**Estado:** Accepted · **Fecha:** 2026-09-23 · **Change:** `extension-firefox-web-store`

**Origen:** plan §6 fila 33; hueco de ADR-038 (solo Chromium / `chrome-extension://`).
Relacionados: ADR-038 (auth extensión + CORS), ADR-012 (cliente web).

## Contexto

La extensión Chromium (fila 24) cubre Guardar en un clic, pero usuarios Firefox siguen
en paste/SPA. Además `EXTENSION_CORS_ORIGINS` solo documentaba / asumía
`chrome-extension://`, insuficiente para temporary add-ons Firefox (`moz-extension://`).

## Decisión

1. **Mismo codebase** `apps/extension`: target `build` → `dist/apps/extension` (Chromium);
   `build-firefox` → `dist/apps/extension-firefox` (outDir separado).
2. **Firefox MV3:** `background.service_worker` + `type: "module"`; `gecko.id`
   `linkvault@linkvault.app`; `strict_min_version` `121.0`. Thin wrapper
   `browser ?? chrome` (sin polyfill obligatorio).
3. **CORS:** `EXTENSION_CORS_ORIGINS` acepta CSV de `chrome-extension://…` **y**
   `moz-extension://…`. Boot **rechaza** cualquier otro esquema. Default vacío = off.
4. **Tiendas:** checklist manual CWS + AMO en RUNBOOK; builds de tienda MUST usar
   `EXTENSION_API_BASE_URL` de producción. Listing live / publish CI **fuera** del DoD.
   Verify local: `extension:lint-firefox` (contrato FF ≥ 121). AMO online al publicar.
5. **Plan:** fila 33 en `docs/design-v0.2.md` §6.

## Enmienda a ADR-038

El punto 6 (CORS) de ADR-038 queda enmendado: la allowlist incluye Chromium **y**
Firefox. Auth `/api/auth/extension/*` y `client=extension` no cambian.

## Alternativas descartadas

- Segundo repo / fork solo Firefox.
- `webextension-polyfill` obligatorio en v1.
- Publicación automática a AMO/CWS desde CI.
- `web-ext lint` 8.x como gate (schema local desactualizado respecto a `service_worker`).

## Consecuencias

- API valida esquemas de origen en config.
- Docs: unpacked Chrome + `about:debugging` Firefox + checklist tiendas.
- Verify: `pnpm nx run extension:lint-firefox` sobre el outDir Firefox.
