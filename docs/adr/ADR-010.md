# ADR-010 — Procedencia por campo en JobPreview

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
El re-enriquecimiento pisaba ediciones manuales (Critic C3).

## Decisión
Cada campo del preview guarda {value, source: auto|manual, by, at, confidence}. El merge automático nunca sobrescribe manual.

## Consecuencias
UI muestra origen del dato.
