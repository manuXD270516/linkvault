# ADR-013 — /p/:slug servido por la API

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
SSR completo por una página pública es desproporcionado (Critic C9, Business B8).

## Decisión
La API devuelve HTML con OG tags; humanos son redirigidos a la SPA; CTA 'Guardar en LinkVault'.

## Consecuencias
Sin Angular SSR en MVP.
