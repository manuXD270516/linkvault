# ADR-001 — Monolito modular NestJS + worker

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
Equipo pequeño; microservicios no amortizan su costo operativo. Votación 6-0.

## Decisión
Una API NestJS con módulos por bounded context y un worker NestJS standalone con BullMQ. Fronteras listas para extraer módulos después.

## Consecuencias
Dos imágenes de backend. Comunicación entre módulos solo por eventos.
