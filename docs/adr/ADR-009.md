# ADR-009 — Outbox pattern Mongo → BullMQ

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
Dual-write entre crear documento y encolar (Critic C2, P0).

## Decisión
Escritura del agregado + `outbox_events` en transacción Mongo; relay publica a BullMQ con jobId determinista. Mongo en replica set de 1 nodo en todos los entornos.

## Consecuencias
Jobs idempotentes. Compose y CI arrancan Mongo con `--replSet rs0`.
