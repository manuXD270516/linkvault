# ADR-014 — Módulo IA: runTask, capacidades, mock 3 modos, ledger, PII, evals, BYOK, degradación

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
Detalle en docs/design-v0.2.md §4.

## Decisión
Punto de entrada LLM: `runTask`; routing por capabilities; structured-output pipeline con un repair prompt; mock
replay/synth/record; ledger+cuotas+breaker; PiiRedactor para proveedores external; eval harness con golden sets; BYOK
cifrado con libsodium; RuleBasedMatcher como degradación.

## Consecuencias
Lint no-restricted-imports para SDKs fuera de libs/ai/infrastructure/providers.

## Enmiendas
- **ADR-036** (change `search`, 2026-09-22): se añade **`embedTexts(texts, ctx)`** como **única** entrada de aplicación
  para **embeddings**. `runTask` permanece reservado a LLM / salidas estructuradas. Misma familia de guards
  (consentimiento, PII, cuotas, breaker, ledger); cadena `AI_EMBED_CHAIN` separada de `AI_CHAIN`.
