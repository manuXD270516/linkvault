# ADR-003 — Cadena de extracción lícita

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
Scraping headless viola ToS y bloquea IPs.

## Decisión
OG/JSON-LD JobPosting → adaptadores por plataforma → extracción LLM → headless solo con flag → edición manual.

## Consecuencias
`FEATURE_HEADLESS_EXTRACTION=false` por defecto. Respetar robots.txt.
