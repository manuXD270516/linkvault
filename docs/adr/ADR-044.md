# ADR-044 — Tags y pinned en `group_links`

**Estado:** Accepted · **Fecha:** 2026-09-23 · **Change:** `group-link-tags-pinned`

**Origen:** enmienda diferida de ADR-026 (tags/pinned fuera del MVP de comentarios) +
diseño de `group-link-tags-pinned`. Relacionados: ADR-026 (note/comentarios),
know-someone-flag (ACL miembro → 404).

## Contexto

Con paste, extensión y discovery el feed del grupo crece sin estructura. Hace falta
etiquetar y fijar links **en la relación grupo↔link**, sin reordenar el cursor ni
filtrar en cliente sobre páginas parciales.

## Decisión

1. **ACL:** cualquier miembro puede `PUT` tags y pinned. No miembro / grupo inválido →
   `404 group_not_found`. Relación ausente → `404 link_not_found`. Sin `403`.
2. **`pinned` = flag + filtro:** default `false`; listado sigue `(sharedAt DESC, _id)`.
   Query opcional `?pinned=true|false`. **No** pin-to-top / sort nuevo.
3. **Tags:** `PUT` reemplaza el array (`$set`). Normalizar (trim, lowercase, colapsar
   espacios, descartar vacíos, dedupe). Caps: máx 8; patrón
   `^[a-z0-9][a-z0-9\- ]{0,31}$` tras normalizar.
4. **Query de grupo aparte:** `listGroupLinksQuerySchema` — `pinned` con
   `z.enum(['true','false']).transform` (**prohibido** `z.coerce.boolean()`).
   `list` + `count` comparten el mismo filter. Lista privada sin `pinned`/`tag`.
5. **Sin fuga / sin outbox:** mutaciones = `$set` en `group_links` sin SearchUpsert.
   Tags/pinned **no** salen en `/p/:slug`, digest semanal ni Meili.
6. **Índice por tag diferido:** `{ groupId: 1, tags: 1, sharedAt: -1, _id: -1 }` **no**
   se crea en este change. Collscan OK en grupos pequeños; crear el índice si el filtro
   por tag duele en producción.

## Alternativas descartadas

- Solo `sharedBy` / solo owner pueden editar.
- Pin-to-top con sort `(pinned, sharedAt, _id)` + cursor/índice nuevos.
- Merge parcial de tags; taxonomía global; tags en links privados.
- Indexación Meili / digest / publicShare de tags o pinned.

## Consecuencias

- Endpoints slim: `PUT …/tags` → `{ tags }`; `PUT …/pinned` → `{ pinned }`.
- Plan §6 fila **30** `group-link-tags-pinned` (tras discovery 29).
- Índice tag = follow-up operativo si hace falta; no bloquea el change.
