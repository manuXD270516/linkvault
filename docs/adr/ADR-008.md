# ADR-008 — Dedupe por platform:externalJobId

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
URLs de una misma vacante varían por plataforma (Critic C1, P0).

## Decisión
Canonicalizador por plataforma produce {platform, externalJobId}; clave de dedupe = platform:externalJobId, fallback urlHash. Índice único parcial.

## Consecuencias
Cada adaptador de plataforma incluye su canonicalizador y tests.
