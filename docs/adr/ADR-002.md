# ADR-002 — JobLink canónico + Application por usuario

**Estado:** Aceptado · **Fecha:** 2026-09-16 · **Origen:** sesión de diseño (group chat + voting) y revisión Critic/Business v0.2

## Contexto
Copiar el link por usuario destruye la vista de grupo. Votación 7-0.

## Decisión
`JobLink` único por vacante; `GroupLink` relaciona link↔grupo; `Application` (userId, linkId) único por usuario.

## Consecuencias
La card de grupo muestra quién postuló (si el usuario lo comparte).
