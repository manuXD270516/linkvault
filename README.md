# LinkVault — starter kit para Claude Code
1. Copia todo (incluye `.claude/` y `.github/`) a la raíz de tu repo vacío.
2. `make setup`
3. `claude` y escribe, en orden: `/lv:context` → `/lv:run next` (repetir 15 veces) — o `make autopilot` para hacerlo todo.
Secuencia de prompts para la UI: `docs/PROMPTS.md`. Detalle: `docs/RUNBOOK.md`.
